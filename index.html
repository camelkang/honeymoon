지도를 클릭해 장소를 추가하세요 (Esc 취소)

⚙️ 지도 설정

기본 지도는 API 키 없이 동작합니다. Google Maps JavaScript API 키를 입력하면 실제 구글 지도로 전환됩니다.

  1. Google Cloud 콘솔에서 프로젝트 생성
  2. "Maps JavaScript API" 사용 설정 → API 키 발급
  3. 키를 여기 붙여넣고 저장 (주소창에 ?key=...로 넣어도 됩니다)

어느 지도든 각 장소의 구글맵 버튼과 구글맵 길찾기 버튼은 항상 구글 지도로 열립니다.
