📲 홈 화면에 앱으로 설치하기

아이폰 (Safari)

  1. Safari로 이 페이지를 열고 아래쪽 공유 버튼(□↑)을 눌러요
  2. "홈 화면에 추가"를 선택해요
  3. 홈 화면의 💍 아이콘으로 열면 앱처럼 전체 화면으로 열려요

안드로이드 (Chrome)

  1. 오른쪽 위 ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

⚠️ 아이폰은 설치한 앱과 Safari가 저장 공간을 따로 써요. 앱에서 ⚙️ API 키를 다시 넣고, 일정은 Safari에서 내보내기 → 앱에서 가져오기로 옮겨주세요.

⚙️ 지도 설정

Google Maps API 키를 넣으면 이 페이지 안에서 구글 지도, 실제 이동 경로·소요시간, 장소 정보(사진·평점·영업시간), 구글 장소 검색을 모두 쓸 수 있어요.

  1. Google Cloud 콘솔에서 프로젝트 선택
  2. 결제 계정 연결 (결제) — 연결이 안 되어 있으면 지도가 어둡게 "For development purposes only"로 표시되고 경로·장소 정보도 막힙니다. 개인 여행 계획 정도는 월 무료 사용량 안이라 보통 과금되지 않아요.
  3. API 라이브러리에서 3개 사용 설정: Maps JavaScript API, Places API (New), Routes API
  4. API 키에 제한을 걸었다면 위 3개 API를 허용 목록에 포함
  5. 키를 여기 붙여넣고 저장 (주소창에 ?key=...로 넣어도 됩니다)
