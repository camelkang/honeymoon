개인정보처리방침

둘이서 · 커플 여행 지도 — 시행일 2026년 10월 4일

둘이서(이하 "앱")는 커플이 여행 일정·장소·숙소·예산을 함께 계획하도록 돕는 앱이에요. 앱은 서비스에 꼭 필요한 정보만 처리하며, 광고나 분석 도구를 쓰지 않고 정보를 판매하지 않아요.

1. 처리하는 정보

로그인하지 않을 때모든 일정·장소·지출·체크리스트는 사용하는 기기 안에만 저장돼요. 서버로 보내지 않아요.
Google 로그인 정보이름, 이메일 주소, 프로필 사진 주소, 계정 식별자(UID). 짝꿍에게 내 이름과 사진을 보여주고 둘의 데이터를 연결하는 데 써요.
여행 데이터도시별 일정, 직접 추가한 장소, 숙소 후보(링크·가격·메모), 좋아요 표시, 장소별 메모, 예약 정보(예약번호·일시·링크), 지출 기록, 준비 체크리스트, 예산 설정. 짝꿍과 실시간으로 함께 편집하기 위해 저장해요.
짝꿍 연결 정보초대 코드(48시간 유효)와 연결된 커플 정보.

위치 정보는 지도에서 "내 위치" 버튼을 누를 때만 기기에서 쓰이며 서버에 저장하지 않아요.

2. 정보를 처리하는 곳 (위탁·제3자 서비스)

  • Google Firebase (로그인, 데이터 저장) — 로그인 정보와 여행 데이터를 저장해요.
  • Google Maps Platform (장소 검색·장소 정보·이동 경로) — 검색어, 장소 이름·좌표가 Google로 전송돼요.
  • OpenFreeMap (지도 그림) — 지도 타일을 받을 때 기기의 IP 주소 등 일반적인 접속 정보가 전달돼요.
  • GitHub Pages (앱 파일 제공) — 앱을 열 때 일반적인 접속 기록이 남을 수 있어요.

각 서비스의 개인정보 처리는 해당 회사의 방침을 따라요. 이 외에 다른 곳에 정보를 제공하지 않아요.

3. 보관 기간

서버에 저장된 정보는 계정을 삭제할 때까지 보관하고, 삭제하면 바로 지워요. 짝꿍과 연결을 해제하거나 계정을 삭제해도, 짝꿍과 함께 만든 일정은 짝꿍의 데이터로 남아요. 만료된 초대 코드에는 개인정보가 들어 있지 않아요.

4. 계정과 데이터 삭제

  1. 앱 오른쪽 위의 계정(프로필) 버튼을 눌러요.
  2. 창 아래쪽의 계정 삭제를 누르고 확인해요.

로그인 계정, 내 프로필, 커플 연결 정보가 바로 삭제돼요. 혼자 쓰던 일정(또는 짝꿍이 이미 떠난 커플의 일정)은 서버에서 모두 지워져요. 기기에 저장된 일정은 앱의 일정 → 초기화로 지울 수 있고, 앱을 지우면 함께 사라져요.

앱을 쓸 수 없는 경우 아래 문의처로 삭제를 요청하면 확인 후 지워 드려요.

5. 이용자의 권리

언제든지 앱에서 내 정보를 확인·수정하고, 짝꿍 연결을 해제하거나 계정을 삭제할 수 있어요. 일정은 일정 → 내보내기로 파일로 받을 수 있어요.

6. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않아요.

7. 안전성

서버의 데이터는 연결된 커플 두 사람만 읽고 쓸 수 있도록 접근 규칙으로 보호되며, 모든 통신은 암호화(HTTPS)돼요.

8. 문의

GitHub 문의 게시판에 남겨 주세요. 방침이 바뀌면 이 페이지에 시행일과 함께 알려 드려요.
