## 파일
- `icon-512.png` — 앱 아이콘 (512×512)
- `feature-graphic.png` — 그래픽 이미지 (1024×500)
- `screenshots/` — 휴대폰 스크린샷 (1080×1920). Actions → **Store screenshots** → Run workflow 로 실제 지도로 다시 찍어 커밋됨
- `site/` — `camelkang.github.io` 저장소에 올릴 앱 인증 파일(`.well-known/assetlinks.json`)

## 출시 순서
1. **Play Console 개발자 계정** 등록 ($25, 신분 확인)
2. **서명 키를 GitHub 시크릿에 등록** — 저장소 Settings → Secrets and variables → Actions → New repository secret
   - `ANDROID_KEYSTORE_BASE64` : 받은 `ANDROID_KEYSTORE_BASE64.txt` 내용 전체
   - `ANDROID_KEYSTORE_PASSWORD` : 받은 `ANDROID_KEYSTORE_PASSWORD.txt` 내용
   - 원본 `upload.keystore`와 비밀번호는 비밀번호 관리자·개인 클라우드 등 안전한 곳에 꼭 보관 (저장소에 올리지 않기)
3. **`camelkang.github.io` 공개 저장소 만들기** → Settings → Pages → Branch `main` / root 로 켜기
   → `site/` 안의 파일(`.nojekyll`, `.well-known/assetlinks.json`)을 올림
4. **Firebase 규칙 다시 게시** — 저장소의 `firestore.rules` 내용을 Firebase 콘솔 → Firestore → 규칙에 붙여넣고 게시 (계정 삭제 기능용)
5. **앱 파일 만들기** — Actions → **Android app (Play Store)** → Run workflow (버전 이름 1.0.0)
   → 끝나면 실행 화면 아래 Artifacts에서 `.aab` 다운로드
6. **Play Console에서 앱 만들기** — 앱 이름 "둘이서 - 커플 여행 지도", 기본 언어 한국어, 앱, 무료
   - 테스트 및 출시 → **비공개 테스트** → 트랙 만들기 → `.aab` 업로드 (Play 앱 서명 사용)
   - 설정 → 앱 무결성 → **앱 서명 키 인증서 SHA-256** 값을 복사 → `site/.well-known/assetlinks.json`에 추가
     (이걸 해야 스토어에서 받은 앱이 주소창 없이 열림)
7. 아래 **스토어 등록정보 / 데이터 보안 / 콘텐츠 등급** 입력
8. 테스터 **12명 이상이 14일 이상** 비공개 테스트 참여 → 프로덕션 출시 신청 (2023년 11월 이후 만든 개인 계정 조건)
