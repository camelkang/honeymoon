# 💍 시드니 신혼여행 인터랙티브 지도

`index.html` 하나로 동작하는 시드니 여행 계획 지도입니다. 브라우저로 열기만 하면 되고, 일정은 브라우저에 자동 저장됩니다.

## 구글 지도 모드 (추천)
⚙️ 설정에 Google Maps API 키를 넣으면 **구글맵을 따로 켜지 않고 이 페이지 안에서** 모두 확인할 수 있어요.

- 구글 지도 위에 날짜별 **실제 이동 경로**(대중교통/도보/자동차)와 구간별 소요시간·노선(🚆 T2, ⛴️ 페리 등) 표시
- 장소 팝업에 **구글 장소 정보**: 사진, 평점·리뷰 수, 주소, 영업시간, 웹사이트
- **🔎 구글 검색**으로 어떤 가게·명소든 찾아서 일정에 추가
- 지도 위 구글 장소 아이콘을 클릭해도 바로 일정에 추가
- 경로·장소 정보는 브라우저에 캐시되어 API 호출을 최소화

### 키 설정 체크리스트
지도가 어둡게 **"For development purposes only"** 로 보이면 결제 계정이 연결되지 않은 상태입니다.
1. Google Cloud 콘솔에서 프로젝트에 **결제 계정 연결** (월 무료 사용량이 있어 개인 용도는 보통 과금되지 않음)
2. API 사용 설정: **Maps JavaScript API**, **Places API (New)**, **Routes API**
3. 키에 API 제한을 걸었다면 위 3개를 허용

## 공통 기능
- 명소·뷰포인트·해변·맛집·카페·바·쇼핑·숙소·교통 등 50곳 큐레이션 (필터, 검색)
- 날짜별 일정: 순서 변경, 다른 날로 이동, 방문 시간, 메모, 추천 일정, JSON 내보내기/가져오기
- 지도 클릭으로 나만의 장소 추가
- 현지에서 길안내가 필요할 땐 "휴대폰 구글맵 앱으로 길안내" 버튼

API 키 없이도 기본 무료 지도로 동작합니다 (이때는 경로가 직선으로 표시됨).
