# 💍 시드니 신혼여행 인터랙티브 지도

`index.html` 하나로 동작하는 시드니 도심 여행 계획 지도입니다. 브라우저로 파일을 열기만 하면 됩니다.

- 명소·뷰포인트·해변·맛집·카페·바·쇼핑·숙소·교통 등 50여 곳 큐레이션 (카테고리 필터, 검색)
- 장소를 날짜별 일정에 담고 순서 변경 → 지도에 날짜별 동선 표시, 구간 거리/도보 시간 표시
- **🧭 구글맵 길찾기로 열기**: 하루 동선을 그대로 Google Maps 길찾기(대중교통/도보/자동차)로 열기
- 지도 클릭으로 나만의 장소 추가, 날짜별 메모, 추천 일정, JSON 내보내기/가져오기 (브라우저 자동 저장)
- 기본 지도는 API 키 없이 동작하며, ⚙️에서 Google Maps JavaScript API 키를 넣으면 실제 구글 지도로 전환 (`index.html?key=...` 도 가능)

좌표·영업시간은 대략적인 정보이니 방문 전 구글맵 버튼으로 확인하세요.
